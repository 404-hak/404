# Политика обработки данных · система «404» (шаблон)

> Шаблон для организации, которая разворачивает систему (инспекция, заповедник). Поля в `[квадратных скобках]` заполнить.
> Основа — 152-ФЗ «О персональных данных». Перед вводом в работу показать юристу организации.

## 1. Оператор
[Полное наименование организации], [адрес], [ИНН/ОГРН]. Ответственный за обработку данных: [ФИО, должность, почта].

## 2. Зачем система обрабатывает данные
Обнаружение незаконного вылова рыбы в [район]: акустические буи слышат мотор и выстрел ночью, дежурный инспектор получает тревогу
и место; записи — доказательства по делу об административном правонарушении.

## 3. Какие данные
| Данные | Откуда | Срок хранения |
|--------|--------|---------------|
| Звук с гидрофонов (2–30 с), из-за которого поднята тревога | буи | до решения по делу + [срок архива] |
| Звук без тревоги | буи | не дольше 24 часов (`CLIP_RETENTION_HOURS`), затем удаляется автоматически |
| Звук, где слышна только речь людей, без тревоги | буи | **не сохраняется** |
| Учётные записи сотрудников: логин, имя, роль, хэш пароля | старший смены | пока человек работает + [срок] |
| Журнал действий: кто и когда начал перехват, закрыл тревогу, вошёл | система | [срок, не меньше срока хранения улик] |
| Текущее положение катера инспектора | планшет/телефон инспектора | не хранится, только текущее значение |
| Журналы сервера (IP-адреса, запросы) | сервер | 14–30 дней |

Аналитика, счётчики, реклама — не используются. В браузере сохраняются только настройки интерфейса (тема, звук, вид).

## 4. Кто имеет доступ
Только сотрудники с учётной записью: **наблюдатель** (смотрит), **дежурный** (решает по тревогам), **старший** (плюс состав команды).
Каждое решение по тревоге записывается в журнал действий; журнал и улики защищены хэш-цепочкой SHA-256, печать цепочки
ежедневно сохраняется вне сервера ([где: бумажный журнал смены / почта / внешний журнал]).

## 5. Передача третьим лицам
- **Яндекс Карты** (спутниковая подложка и снимок места тревоги) — получают IP-адрес и адрес страницы дежурного.
- **Esri World Imagery** — только если ключ Яндекса не задан; серверы за рубежом (трансграничная передача). В проде рекомендуется только Яндекс.
- **Telegram** (если включены уведомления `TELEGRAM_BOT_TOKEN`) — получает текст тревоги: время, буй, сектор, вид звука. Звук не передаётся. Серверы за рубежом — решить, допустимо ли это в организации.
- **Open-Meteo** — запросы погоды идут с сервера, данных людей не получает.

## 6. Защита
HTTPS; вход по паролю (scrypt), ограничение попыток; роли; журнал действий; ежедневные резервные копии (`deploy/backup.sh`) с хранением 30 дней;
доступ к серверу — только у [ответственного].

Узнать, обрабатываются ли их данные, потребовать уточнения или удаления, если это не мешает производству по делу, — запрос на [почта].
Ответ — в течение 10 рабочих дней.
