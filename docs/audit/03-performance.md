# Производительность

Замеры на сборке `web/dist` и локальном сервере (1280×720). Статус: ✅ · 🟡 · ⏳.

## Что грузится при первом открытии

| Ресурс | Было | Стало (gzip) |
|--------|------|--------------|
| `index-*.js` (React, Leaflet, сайт) | 590 КБ | **190 КБ** |
| `index-*.css` | 147 КБ | ~42 КБ |
| `geo/delta-osm.geojson` (схема дельты) | 1 341 КБ | **378 КБ** |
| `/api/state` | 24 КБ | ~5 КБ |
| Шрифты Inter 300–700 + JetBrains Mono 400/500 (кириллица + латиница) | ~14 файлов woff2 | без изменений |
| `Map3D-*.js` (three.js) | 548 КБ | грузится только по кнопке «3D» ✓ |

Итого первый заход: было ≈ 2,1 МБ, стало ≈ 0,7 МБ. Повторный заход — почти ноль: файлы сборки кэшируются навсегда (в имени хэш).

## Бюджет на будущее

Первый заход ≤ 500 КБ (gzip), JS основного пути ≤ 150 КБ, LCP ≤ 2,5 с на 4G, 60 к/с при движении карты на ноутбуке 5-летней давности.
