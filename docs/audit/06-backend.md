# Бэкенд (`api/`)

FastAPI + Uvicorn, один процесс; SQLite (WAL) + папка звуковых клипов; нейросеть на NumPy (`app/audio/model.py`, веса `model.npz`);
симулятор буёв и демо — в том же процессе. ~1 700 строк в `app/*.py` + ~1 600 в `app/audio`. 44 теста pytest.
Статус: ✅ · 🟡 · ⏳.

## Сильные стороны

- Понятный API с моделями Pydantic и автодокументацией; звук-улика хранится под SHA-256 и входит в хэш-цепочку тревог.
- Тяжёлая работа (нейросеть, синтез) вынесена в `asyncio.to_thread`.
- Прогноз риска объясним (луна, день недели, вода, ветер); погода с запасным сезонным режимом.
- Тесты не трогают рабочую базу (`conftest.py`).
