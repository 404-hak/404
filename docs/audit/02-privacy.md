# Приватность и персональные данные

Статус: ✅ сделано · 🟡 частично · ⏳ не сделано.

## Какие данные есть

| Данные | Где | Чьи | Риск |
|--------|-----|-----|------|
| Звук с гидрофонов (клипы 2–30 с) | `api/data/clips/*.wav`, таблица `clips` | любые люди у воды: рыбаки, туристы, сами инспекторы | **голос человека — персональные данные** (152-ФЗ); нейросеть уже различает «голоса людей» |
| Координаты катера инспектора | `state.inspector`, рассылается по WebSocket | сотрудник | оперативная тайна и данные о местоположении человека |
| Тревоги: время, место, класс звука, совпадение с катером («тот же катер, что 5 мая») | SQLite `alerts` | косвенно — владельцы катеров | профилирование; доказательства в деле |
| Адреса (IP) посетителей | журнал uvicorn | дежурные | обычные журналы |
| Настройки интерфейса | `localStorage` (тема, звук, вид дымки, свёрнутый лист), `sessionStorage` (заставка) | — | нет персональных данных ✓ |
| Cookie доступа `access404` | браузер дежурного | — | только подпись токена, `HttpOnly` ✓ |

Аналитики, счётчиков, сторонних шрифтов нет ✓ (шрифты свои, из `@fontsource`).

## Рекомендуемые сроки хранения

- звук тревоги и её запись в цепочке — сколько требует процесс (до решения по делу + архив);
- звук без тревоги — **24 часа** (нужен только для разбора «почему не сработало»);
- клипы с речью — **не хранить**;
- журналы сервера — 14–30 дней;
- координаты катера — не хранить историю, только текущее положение.
