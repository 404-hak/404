# Фронтенд (`web/`)

React 18 + Vite 5 + TypeScript + Tailwind; карта — Leaflet (офлайн-схема), Яндекс Карты (спутник), three.js (3D, отдельный чанк);
фон и дымка — свои шейдеры WebGL; движение и «своё вместо браузерного» — `upkMotion.ts`, `upkUi.ts` вне React.
~8 000 строк в `web/src`. Статус: ✅ · 🟡 · ⏳.

## Сильные стороны

- Строгий TypeScript, сборка проверяет типы (`npm run build` = `tsc --noEmit && vite build`).
- 3D грузится по требованию; анимации стоят при скрытой вкладке; учтены «уменьшить движение» и высокая контрастность.
- Откаты без пересборки: `?design=classic`, `?layout=panels`.
- Свои меню, подсказки, проигрыватель, перетаскивание — с клавиатурой (стрелки, Esc, Enter), `aria-*` расставлены (≈110 мест).

## Порядок работ

1. Выбрать оформление (W2) — это сразу −30 % CSS и половина хрупких правил.
2. `lazy()` для разделов и заставки (03-performance F3).
3. Тесты: Vitest для чистых функций + 3 сценария Playwright в CI.
4. Доступность: «Обычный указатель», клавиатура на карте, ошибки запросов.
