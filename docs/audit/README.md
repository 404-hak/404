## Что сделать в первую очередь

**До любого показа вне команды (P0):**
1. ✅ На сервере задать `ACCESS_TOKEN`, раздать дежурным ссылку `…/?access=…` — S1, S2.
2. ✅ На настоящих данных — `DEMO=0` (иначе «Сбросить» стирает улики) — S1.
3. ⏳ Задать `BUOY_TOKEN` (лучше — свой на каждый буй) — S3.
4. 🟡 Развернуть за HTTPS с резервными копиями — готово в `deploy/` (`docker compose up -d --build`), проверить первым запуском на сервере — I1, I3.
5. ✅ Звук без тревоги хранится не дольше суток, речь без тревоги не хранится — P1, P4.

**Следующий шаг (P1):** учётные записи и роли с журналом действий (S13, B1); ленивые разделы (F3); тесты фронтенда (W1);
выбор одного оформления (W2); разделение `World` (B2); отдельная база для демо (B4); строгая CSP после проверки с ключом Яндекса (S8).

## Как включить защиту в Codespaces

```bash
export ACCESS_TOKEN=$(python3 -c "import secrets;print(secrets.token_urlsafe(24))")
export DEMO=1            # для показа; на настоящих данных — 0
bash scripts/start.sh
echo "Ссылка для телефона: https://<адрес-порта-8000>/?access=$ACCESS_TOKEN"
```
Постоянно — добавить `ACCESS_TOKEN` в секреты Codespaces (как `VITE_YANDEX_MAPS_KEY`).
